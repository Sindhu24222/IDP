Email automation settings

Checking…
When a certificate is generated or approved, SmartCert emails the recipient their certificate as a PDF attachment, with the verification link. Sending is done by the SmartCert server (server.js) using your email provider, so your email password never sits in this page.
The Certificate ID is added at the end, e.g. https://your-domain.com/verify/CERT-1001

What the recipient receives

—
SUBJECT

        
📎 Attachment: CERT-1001.pdf

      

      
If no mail server URL is set, Send downloads the PDF and opens a ready-made email draft in your mail app — you attach the PDF and press Send. Fully automatic emailing needs the mail server.
